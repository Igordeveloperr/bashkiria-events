# Описание типов данных

## Схема события

| Поле | Тип | Описание |
| --- | --- | --- |
| `id` | UUID | Идентификатор |
| `title` | text | Название как у источника |
| `normalized_title` | text | Название для дедупликации и поиска |
| `category` | enum | Концерт, спектакль, выставка, фестиваль, кино, экскурсия, другое |
| `tags` | text[] | Метки: джаз, дети, бесплатно, башкирский язык |
| `date_start` | timestamp | Начало |
| `date_end` | timestamp | Окончание, если известно |
| `duration_min` | int | Длительность в минутах, если известна |
| `city` | text | Город или населённый пункт |
| `venue` | text | Площадка |
| `address` | text | Адрес |
| `lat`, `lon` | numeric | Координаты, если известны |
| `description` | text | Краткое описание |
| `price_min`, `price_max` | int | Цена в рублях; 0 — бесплатно |
| `is_free` | bool | Признак бесплатного входа |
| `age_limit` | int | Возрастное ограничение: 0, 6, 12, 16, 18 |
| `language` | text | Язык мероприятия, если указан |
| `org_link` | url | Ссылка на организатора или билеты |
| `source_url` | url | Источник, откуда взято событие |
| `source_type` | enum | Ручной ввод, импорт, RSS, API, страница |
| `source_hash` | text | Хеш исходной записи для идемпотентности |
| `verified_at` | timestamp | Когда источник проверен |
| `confidence` | numeric | Уверенность извлечения, 0–1 |
| `status` | enum | Опубликовано, черновик, отменено |
| `dedup_key` | text | Ключ дедупликации |
| `created_at` | timestamp | Время создания |
| `updated_at` | timestamp | Время последней модификаций |
| `embedding` | vector | Векторное представление события (для семантического поиска) |
