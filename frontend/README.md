# Веб-интерфейс

`web` — React + TypeScript + Vite, сервер интерфейса Fastify. Сервер обращается к микросервисам через Traefik, хранит ключи и устанавливает защищённую анонимную сессию. Существующая база и миграции используются через API сервисов.

## Запуск

Из корня репозитория, Docker Desktop должен работать:

```powershell
docker compose --profile gateway up -d --build --wait
```

Сайт: http://localhost:8080, модератор: http://localhost:8080/admin, помощник: http://localhost:8080/assistant. Прямой порт сайта: 5173. Пароль модератора — `WEB_ADMIN_PASSWORD` корневого `.env`. Файл `.env` не коммитить. Для ИИ нужны настройки `backend/ai/.env` по документации агента.

В корневом `.env` нужны существующие ключи сервисов и новые `WEB_SESSION_SECRET` (32 случайных байта в hex, 64 символа), `WEB_ADMIN_PASSWORD` (минимум 16 символов), `WEB_PUBLIC_ORIGIN` (внешний адрес сайта). Для текущей локальной установки значения уже созданы. При смене секрета старые сессии станут недействительными.

Для разработки нужен **Node.js 22.12+**, рекомендуется 24:

```powershell
cd frontend/web
npm ci
# При первом запуске на другой машине создать .env из .env.example и заполнить секреты.
npm run dev
```

Vite: http://localhost:5173, сервер: http://127.0.0.1:5174. Gateway и сервисы должны работать. Ключи сервисов читаются из корневого `.env`, локальные значения — из `web/.env`, переменные процесса имеют приоритет. `VITE_` переменные с секретами запрещены. Для проверки сборки: `npm run build`; проверки сессии и API: `npm test`; браузерные сценарии: `npm run test:e2e` (установленный Microsoft Edge, запущенный сайт на 8080; другой адрес задаётся `WEB_TEST_URL`).

## Страницы

| Адрес | Назначение |
| --- | --- |
| `/` | Афиша: поиск, город, площадка, категории, даты, цена, возраст, бесплатные события, сортировка и пагинация |
| `/events/:id` | Постоянная ссылка, источники, актуальность, отмена, описание, адрес и организатор |
| `/favorites` | Избранное в localStorage браузера, до 50 записей |
| `/assistant` | Многошаговый диалог с агентом, согласие на подписку, повтор запроса и переход к обычному поиску |
| `/subscriptions` | Создание, изменение, удаление одной или всех подписок |
| `/notifications` | Подборки пользователя и отметка прочтения |
| `/feedback` | Вопрос, уточнение события, заявка организатора, история обращений |
| `/admin` | Вход, ручное создание, редактирование и модерация, журнал, импорт JSON/CSV, сбор, справочники и обращения |
| `/embed` | Генератор iframe с городом, категорией, периодом и высотой |
| `/widget` | Изолированная афиша без пользовательской сессии и сторонних cookies |
| `/about` | О проекте, источниках и данных |

Фильтры каталога находятся в URL: `q`, `city`, `venue`, `category`, `day=today|tomorrow|weekend|week`, `from`, `to`, `maxPrice`, `age`, `free=true`, `sort=date_asc|price_asc|relevance`, `page`. Даты включительно по времени Уфы. В публичной выдаче только опубликованные актуальные события; отменённые доступны по прямой ссылке. Пустое поле цены или времени не заменяется выдуманным значением.

## API сервера интерфейса

Все адреса ниже относительно адреса сайта. Это внутренний контракт браузера; версионированные публичные API и OpenAPI микросервисов описаны в корневом README.

| Метод | Endpoint | Назначение / доступ |
| --- | --- | --- |
| GET | `/health` | Проверка процесса |
| GET | `/api/session` | HttpOnly-сессия и CSRF-токен |
| POST / DELETE | `/api/session/admin` | Вход с `{password}` / выход модератора |
| POST | `/api/session/telegram` | Валидация подписанного `{initData}` при подключённом боте |
| GET | `/api/events` | Публичный список; фильтры выше, `pageSize` до 24 |
| GET | `/api/events/:id` | Публичная карточка, ETag |
| GET | `/api/cities`, `/api/categories`, `/api/venues?cityId=UUID` | Справочники, Cache-Control 60 секунд |
| POST | `/api/chat` | `{sessionId,requestId,message,subscriptionConsent}`; user ID задаёт сервер |
| GET | `/api/me/subscriptions`, `/api/me/notifications`, `/api/me/feedback` | Собственные записи, `page`, `pageSize` до 100 |
| POST | `/api/me/subscriptions` | Создание с `consentConfirmed: true` |
| PUT | `/api/me/subscriptions/:id` | Изменение с `expectedVersion` и подтверждением |
| DELETE | `/api/me/subscriptions/:id`, `/api/me/subscriptions` | Отписка одной / всех |
| PATCH | `/api/me/notifications/:id/read` | Прочтение |
| POST | `/api/me/feedback` | Обращение; обязателен UUID `Idempotency-Key` |
| GET | `/api/admin/events` | Модератор: `page`, `status=draft|published|cancelled` |
| POST | `/api/admin/events` | Ручной ввод, UUID `Idempotency-Key` |
| GET | `/api/admin/events/:id/audit` | Журнал изменений |
| PATCH | `/api/admin/events/:id/review` | Версия, решение и комментарий |
| POST | `/api/admin/imports/:format/:dataset` | JSON / сырой CSV; до 5 MiB, правила импорта задаёт parser |
| GET | `/api/admin/sources`, `/api/admin/runs`, `/api/admin/stats` | Источники, сбор и статистика |
| POST | `/api/admin/runs/:source` | Поставить сбор в очередь, до 10 страниц |
| DELETE | `/api/admin/runs/:id` | Отмена сбора |
| GET | `/api/admin/feedback` | Очередь обращений, `page` |
| PATCH | `/api/admin/feedback/:id/review` | Обработка обращения |
| POST | `/api/admin/reference/cities`, `/api/admin/reference/venues` | Создание справочников |
| POST | `/api/admin/reference/venues/:id/aliases` | Алиас площадки |
| POST | `/api/admin/reference/normalize` | Нормализация первых 100 карточек; объём явно указан в интерфейсе |

Изменяющие запросы требуют cookie и `X-CSRF-Token` из `/api/session`. Ошибки: `{type,title,status,code,instance,traceId,errors}`. Персональные и административные ответы — `no-store`. Лимит 150 запросов/мин/IP, чат 12/мин, обращения 5/мин, вход 8/15 мин. Таймаут сервисов 30 секунд, ИИ 120 секунд. Модераторская сессия действует 8 часов, анонимная — 90 дней. Очистка cookies теряет доступ к анонимным подпискам; перенос между устройствами требует будущей идентификации через Telegram.

ИИ вызывается через `/ai/api/chat`. Сетевой повтор сохраняет `requestId`, после `generation_failed` создаётся новый ID. Текст ответа отображается без исполнения HTML. Текущий контракт агента возвращает текст: карточки показываются только при наличии UUID в ответе и после получения записи из публичного каталога. Для гарантированного набора карточек агенту нужен структурированный массив идентификаторов в контракте ответа. Трассировка отображается, если агент вернул `trace_id`. Фронтенд не заменяет ограничения инструментов, планировщик и метрики качества агента.

## Telegram Mini App и будущий бот

Веб-приложение адаптивное от 360 px. При запуске из Telegram подключается SDK, кнопка назад и тема. Подпись `initData` проверяется сервером (HMAC, срок 5 минут), `initDataUnsafe` не используется как удостоверение личности. Настройка `TELEGRAM_BOT_TOKEN` только серверная; пока токен не задан, Telegram-вход отключён. Для запуска в Telegram необходим публичный HTTPS-адрес и настройка Mini App у бота.

Будущий бот размещается рядом в `frontend/bot`. Доставка уведомлений идёт через API Interaction: бот забирает доставки с lease и подтверждает результат. В этой задаче создан сайт; обработчики Telegram-команд и доставка ботом пока не реализованы. Реализация всего уровня ТЗ также зависит от возможностей агента и отдельного отчёта по метрикам, описанных в его документации.
