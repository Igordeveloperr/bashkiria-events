# Telegram-бот

Место для будущего отдельного проекта бота. Общий интерфейс Mini App находится в `../web`; копировать его в бота не требуется. Бот открывает публичный HTTPS-адрес сайта и забирает уведомления через API Interaction с lease и подтверждением доставки. Токен бота и delivery key хранятся только на сервере.
